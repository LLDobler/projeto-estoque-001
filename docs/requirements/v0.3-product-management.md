# v0.3 - Product Management

## Requirements

- The system must allow the user to register new products in stock.
- The system must allow the user to remove products from stock.

## Business Rules

### Product Registration

- When a new product is registered, its quantity must start at 0.
- The system must not allow products to be registered with numerical-only names.
- The system must not allow products to be registered with empty names.
- The system must not allow duplicate names during the registration process.
- Differences between uppercase and lowercase must be ignored when checking for duplicates.
- The system must ignore leading and trailing whitespace when checking for duplicate names.

### Product Deletion

- While searching for the product to be deleted, the system must ignore leading and trailing whitespace.
- While searching for the product to be deleted, the system must ignore uppercase and lowercase differences.
- The system must display a "product not found" warning message when the user searches for a product that is not registered.
- To remove a product from stock, the system must ask the user for confirmation.
- To confirm the deletion, the user must enter the exact name of the registered product they want to delete.
- If the confirmation is wrong or cancelled, the product must not be deleted.

### Operation Safety

- If the user cancels an operation, the stock must not be changed.
